AI Tutor

Chat with an AI tutor about whatever lesson you're on — a 💬 button appears while reading. This app has no backend server, so there's no way to proxy this safely for everyone; instead, paste your own Anthropic API key below and the app calls Claude directly from this browser. Your key is stored only in this browser's local storage — never sent anywhere except directly to Anthropic — but anyone with access to this device could find it in dev tools, so only use this on a device you trust.

Accessibility

Adjust text size or enable wider letter and word spacing, which measurably helps reading speed for many dyslexic readers. Correct/incorrect quiz answers are also marked with a ✓/✗ icon, not color alone.

Streak Reminders

Get a nudge if you haven't studied yet today. This app has no backend, so it can only notify you while Synthesis is open in a browser tab (foreground or background) — not after the tab is fully closed.

Backup & Restore

Your progress lives only in this browser unless you sign in with Google above. Download a backup so clearing browser data, switching browsers, or moving devices doesn't mean starting over.

Reset App

Start fresh! This will reset ALL progress including: XP, levels, streaks, completed lessons, badges, flashcards, workouts, and all saved data. Use this after updating content or to start over.
