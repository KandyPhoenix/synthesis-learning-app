# HITT 1211 Syllabus Crosswalk

Maps every item in the HITT 1211 syllabus to the Synthesis lessons that cover it,
across two books in the `him` category, each living in its own module file:

- **`hitt-1211`** — HITT 1211: Health Information Systems — 28 lessons, 407 cards — `hitt-1211-data.js`
- **`ahima-domains`** — AHIMA Domains — 36 lessons, 527 cards — `ahima-domains-data.js`

Lessons **21–28** of HITT 1211 and **33–36** of AHIMA Domains were added specifically
to close gaps found by auditing the existing card body text (not lesson titles) against
this syllabus. Everything else was already present.

## 5. How coverage was verified

Coverage was audited against **card body text**, not lesson titles — titles overstate
coverage. The "before" column was measured against the book modules as they stood on
`main` before this work; regenerate it with:

```
git show main:hitt-1211-data.js > baseline.js   # then dump card text and grep
```

Representative before/after counts of case-insensitive matches:

| Term | HITT 1211 before | after |
|---|---|---|
| `encoder` | 1 (incidental) | 51 |
| `personal health record` / `PHR` | 1 sentence | 41 |
| `notifiable` / `syndromic` / `NNDSS` | 2 passing | 22 |
| `EDMS` / `document imaging` / `backfile` | 3 passing | 19 |
| `keyboard` / `touch typing` / `WPM` | 3 passing | 19 |

| Term | AHIMA Domains before | after |
|---|---|---|
| `flow sheet` / `flowsheet` | 0 | 27 |
| `form design` / `forms committee` / `content governance` | 0 | 5 |
| `Power BI` / `Tableau` / `analytic software` | 0 | 11 |
| `data collection method` | 0 | 4 |
| `compliance plan` | 0 | 11 |

Structural checks run on every new lesson:

- 14 cards minimum, 3+ quiz cards, every card carries a full-canvas SVG
- `viewBox="0 0 1100 1100"`, `#1a1a2e` background, no banned text colors
- Quiz cards expose sibling `question` / `options` / `explanation` so
  `exam-center.js` can harvest them (**36 new exam questions**, 3 per lesson)
- Exactly one correct option per quiz; all distractors addressed in the explanation
- `data.js` reparses after every splice; whole-app check confirms only these two
  books changed (142 books, 20 categories, otherwise unchanged)
- Verified in a real browser against the app's own
  `ExamCenter.harvestLessonQuestions()`: 36 new questions harvested (3 per lesson),
  HITT 1211 total 94, AHIMA Domains total 161, question objects well formed
  (4 options, exactly one correct, explanation present). App loads, SVGs render,
  no console errors.

## 6. Where these courses live

Both courses are **external book modules**, not inline in `data.js`:

| File | Global | Size |
|---|---|---|
| `hitt-1211-data.js` | `window.HITT_1211_BOOK` | ~2.0 MB |
| `ahima-domains-data.js` | `window.AHIMA_DOMAINS_BOOK` | ~2.5 MB |

Each is loaded by `index.html` **before** `data.js` and integrated by the
`externalBooks` array inside `integrateExternalCategories()`. That loader replaces
a same-id book if one already exists.

**Edit these two courses in their own files — not `data.js`.** The book objects have
the same shape they would inside `data.js`, so tooling works unchanged once pointed
at the right path. Changes made to a copy inside `data.js` would be silently
overwritten by the module at load time.

This structure exists because `data.js` had grown against GitHub's hard **100 MB**
per-file limit. It is now ~57 MB with the large books extracted.

## 7. Caveat on quantitative claims

Figures quoted in lesson text (cost-per-duplicate, alert override rates, productivity
gains, adoption percentages) are **illustrative and hedged**, not sourced citations.
They are accurate as commonly reported ranges and are worded to signal that
("commonly cited," "has often fallen short"). Do not quote them to an instructor as
sourced figures without verifying against the primary source — which is itself the
research habit Lesson 21 teaches.
